# 诸告板

跑团招募、成员管理与团内点赞网站。前端使用 React/Vite；`functions/api/[[path]].js` 是 Cloudflare Pages Functions API，D1 保存业务数据，R2 保存团封面和用户头像。

## 使用说明（普通功能）

- **登录与档案：**输入 QQ 号并使用发送到 QQ 邮箱的验证码登录。个人档案可修改昵称、头像、简介、喜好与雷区（各最多 6 个，每个最多 6 个中文字 / 12 个英文字母；前端输入与后端保存双重限制），也会展示已结团的主持和参团记录。
- **浏览与报名：**网团、面团、宣群分板块展示；可按团名、主持、规则、时段与日期筛选，点击卡片查看详情。登录后可报名，报名后可查看主持联系方式；锁车前且开团日期前可取消报名。满员、锁车或到期后不再公开招募。
- **发布与团务：**在对应板块发布内容，可一次选择多个时段。在「团务管理」修改、增加时段、锁车或重新开放；主持还可移出玩家、结团或弃团。宣群不设结团操作。
- **签到与点赞：**每天签到可获得 1 张玩家点赞券，0点刷新。普通用户连续签到每满 7 天获得 1 张 GM 点赞券。主持结团后，同团成员可在团详情使用点赞券。
- **反馈与举报：**从个人档案或团务管理进入。举报需填写被举报者的昵称或 QQ 号，并附至少一张图片。头像菜单的「工单」展示自己的反馈、举报及受理状态，每 15 秒刷新，与后台共用记录。

## 会员权益

- **已开放：**会员期间累计签到每满 7 次，获得 2 张 GM 点赞券；中断签到不清零，比普通用户多 1 张。每天签到仍可获得 1 张玩家点赞券。会员到期后恢复普通签到规则，续费后保留此前的会员累计次数。
- **已上线：**自定义展示铭牌可在个人档案中设置。
- **开通与续费：**① 在爱发电赞助，私信自动收到会员 Key，到「升级会员 / 续费会员」弹窗激活；② 加交流群 917744498 联系站长（无法使用爱发电时的备用通道，长期保留）；③ 站长在后台「账号」直接赠送。到期时间显示在个人档案。

## 本地开发

需要 Node.js 22 和 Wrangler。运行 `npm ci`、`npm run db:migrate:local`、`npm run build`，然后运行 `npm run dev:pages`。Pages Functions 与本地 D1/R2 由 Wrangler 启动；单独运行 `npm run dev` 只适合查看静态 UI。

若要测试登录，在未提交的 `.dev.vars` 中设置 `RESEND_API_KEY` 和 `OTP_SECRET`。`RESEND_API_KEY` 是 Resend API 密钥；`OTP_SECRET` 是独立随机密钥，用于验证码 HMAC。另需为后台设置 `ADMIN_PASSWORD`，机器人测试桥接设置 `BOT_BRIDGE_TOKEN`。邮件发送地址默认 `诸告板 <zgb@pigbee.fun>`（站主自有域名，已在自有 Resend 账号验证）。不要把任何密钥加入 Git。

发布和编辑统一使用最多 6 个自定义标签，每个最多 6 字；不再提供限选标签或后台预设标签配置。历史限选标签在读取时合并为自定义标签，最多保留 6 个，每个超过 6 字的部分截断；原始历史数据保留。网团游戏平台支持 QQ。

## 数据与接口

初始 D1 为空，不自动导入演示账号或团。登录时输入 QQ 号，后端向 `<QQ号>@qq.com` 发送六位验证码，十分钟有效；单号 60 秒内不可重发，每小时最多五次，同一 IP 每小时最多二十次；一个验证码最多尝试五次。登录成功后建立 30 天的 HttpOnly 会话。该流程验证 QQ 邮箱收件能力，不是腾讯 QQ OAuth。

**报名邮件通知：**玩家报名成功后，用同一个 Resend 通道给该团 GM 发一封提醒（默认收件地址 `<GM的QQ>@qq.com`，GM 可在个人档案改邮箱或关闭）。逐次发送，每有一位玩家报名发一封；取消报名不通知。发信整段走 `context.waitUntil`，失败只写 `signup_mail_log`，不影响报名结果。`migrations/0025_signup_mail.sql` 添加 `users.notify_email`、`users.signup_notify_enabled` 与日志表，**部署代码前必须先应用该迁移**。邮件正文模板在 `functions/api/[[path]].js` 的 `SIGNUP_MAIL_TEMPLATE` 标记块内，改文案后运行 `node scripts/gen-signup-mail-preview.mjs` 重新生成预览页。

主要 API 在同源 `/api` 下：`auth/request-code`、`auth/verify`、`auth/me`、`auth/logout`、`campaigns`、`campaigns/:id`、`campaigns/:id/signup`、`campaigns/:id/members/:qq`、`campaigns/:id/finish`、`profile`、`profile/avatar`、`checkin`、`praise`、`upload`。写操作以会话身份执行。公开团列表只返回未锁车、未结团且未满员的团；其余团仅对 GM 和已报名玩家保留。弃团会删除该团、成员记录和团内点赞。

`migrations/` 为 D1 模式文件。`users.qq` 是不可修改的身份主键；`users.avatar_key` 指向 R2 头像。`campaign_memberships` 是参团记录的唯一来源，`campaigns.max_players` 不包含 GM。只有主持手动结团后，该团才进入成员个人档案；每日签到按香港日期获得玩家点赞券，普通用户连续签到每满七天获得 1 张 GM 点赞券；有效会员累计签到每满七次获得 2 张，中断不清零。团内点赞必须绑定已结团的团，且只能由该团成员发出。举报须指定站内昵称或 QQ 号，后台按被举报账号统计次数；黑名单支持限时或永久生效，生效期间禁止报名，手动移出后再次加入会重新计时。预定日期过后自动锁车；修改单团时间到未来后，主持可手动重新开放。封车按开团时段分别计时（北京时间）：早场当天 12:00、午场当天 18:00、晚场次日 00:00，到点由后续请求触发的扫库（每实例 60 秒节流一次）自动封车并结算名单；封车后 0 人报名的网团/面团标记为弃团，宣群不参与弃团标记。已过封车时间的时段不能再发布或新增，前端日历会直接置灰。站点清空浏览器数据不影响这些服务器记录。

批量发布时，每个日期与时段分别创建独立的 `campaigns` 记录，使用 `batch_id` 供板块列表合并展示和详情切换。`kind` 区分网团、面团和宣群；旧记录默认网团。三个板块分别展示，均进入同一机器人广播队列，事件包含 `kind`。面团使用一个输入框填写省份和城市，合计最多八个字；完整地址另填，并在卡片标签下方展示。旧面团分开保存的省份和城市仍会合并展示。宣群使用自填平台及预设或自填方式。宣群不设置招募人数，不接受站内报名；登录后可查看联系方式。宣群管理只保留封车作为结束操作，封车后从板块隐藏且不能重新开放；不提供锁车、结团或弃团按钮。网团发布日历仍限 31 天，面团和宣群可选择任意未来日期。报名、成员、点赞、锁车、结团与弃团按单条记录处理；批量团的简介和标签统一修改，一个批次只写入一条广播事件。部署前须应用 `0009_campaign_batches.sql`、`0010_campaign_closure.sql`、`0012_campaign_completion.sql`、`0013_campaign_sections.sql`、`0014_offline_province.sql`、`0015_feedback_reports.sql`、`0016_checkin_streak.sql` 和 `0017_reports_blacklist.sql`。

团务管理将批量团折叠成一个主团；主团保存通用信息，新增时间点从该信息复制。主团的“修改”可同步所有时段的简介和标签，并更新之后新增时段的模板；各时段仍可单独锁车、结团或弃团。主团在团务管理中保持可见；个人档案仅逐团记录已结团的时段。已有批量团通过 `0011_campaign_batch_templates.sql` 补建主团信息，部署新版 Functions 前需先应用此迁移。

## 管理后台

访问 `/admin`。后台只认站内 QQ 登录会话 + 角色：站主 QQ `407457008` 使用已验证的站内登录会话获得管理员权限，签到旁显示「后台」入口；其他管理员由站长在后台「账号」任命，可进后台但不自动获得会员。退出后台会同时退出站内登录。旧的密码应急通道已下线，`ADMIN_PASSWORD` 不再是后台登录凭据。

后台首页为数据看板，汇总用户增长、团次状态、报名、点赞、登录会话、板块分布、热门规则及反馈举报队列；「团务状态」包含招募中、封车、结团、弃团、累计报名与平均满员率。弃团来自物理删除团之前写入的 `campaign_abandons` 日志，自 `0032` 迁移上线起累计，宣群历史记录删除不计入。内容配置、账号、反馈与举报、封存团务、资源审核各用独立入口。

「反馈与举报」合并为一个分页，里面再分「反馈 / 举报」两页；未处理工单默认展示，已解决与已驳回分别折叠。反馈和举报写入 D1，图片存入 R2；单次最多 9 张且每张不超过 5MB，举报至少需要 1 张图片。管理员可填写备注并标记处理中、已解决或已驳回。账号列表按 QQ 号或昵称搜索、分页显示，点选账号可查看送礼、收礼与会员发放记录。

「封存团务」只列网团 / 面团中已封车与已结团的团（宣群「结束宣发」不在此列），可按状态筛选并展开查看简介、详情、联系方式、时间与报名名单。「资源审核」中，玩家新分享或**改动链接地址**后会进入待审核，只有通过后才展示在首页爱心资源页；只改标题 / 备注 / 标签 / 分页 / 地址类型不重新审核，被驳回的资源任意编辑后可重新提交。管理员可通过、驳回（可填原因，原因会显示给分享者）、退回待审或删除资源。存量资源在 `0032` 迁移时统一视为已通过。

## QQ 新团广播桥接

`POST /api/campaigns` 将团与 `campaign.created` 事件在同一个 D1 事务写入。测试机器人凭独立 Secret `BOT_BRIDGE_TOKEN` 每 15 秒从 `GET /api/internal/bot/events` 领取一个事件，完成原有群发后提交 `POST /api/internal/bot/events/{eventId}/ack`，正文为 `{ "claimId": "..." }`。事件携带 `eventId`、`campaignId`、`kind`、`rule`、`claimId`；`kind` 为 `online`、`offline` 或 `promo`，供机器人区分播报板块，旧机器人可忽略新增字段。广播不含链接。租约为 120 秒，过期事件可重新领取。如需搭建测试站点，必须使用与生产不同的 D1、R2 和 Secret，且仅由双测试群机器人消费。网站发布接口不依赖机器人在线；迁移 `0003_bot_outbox.sql` 必须先于新代码应用。

测试环境已移除：Cloudflare 账号下当前只有生产项目 `zgb-abc`，`zgb-trpg-staging` 项目并不存在，配套的 `wrangler.staging.jsonc` 与 `scripts/deploy-staging.ps1` 已从仓库删除（Git 历史可恢复）。如需重建测试站，须另行创建 Pages 项目、独立 D1/R2，并单独设置 `ADMIN_PASSWORD`、`BOT_BRIDGE_TOKEN`、`OTP_SECRET`、`RESEND_API_KEY`；不得复用生产绑定或生产 Secret。Wrangler Pages 不接受 `--config` 自定义配置路径。

## 赞助会员 Key（爱发电自动发货）

早期基于 Ed25519 验签的兑换码已下线（`membership_redemptions` 保留为空表，仅为兼容旧迁移）。现行流程不依赖私钥：

1. 后台「会员激活」批量生成 Key（1–100 个，可选 1/2/3/6/12 个月；12 个月按 365 天，其余每月 30 天），或导入已有 Key（单次最多 5000 个、单个最长 200 字符，保留原始大小写）。生成后可一键复制纯文本（一行一个）。
2. 爱发电「个人页 → 设置 → 赞助方案 → 高级选项 → 添加自动随机回复」，把 Key 逐行粘贴保存。粉丝发电后平台随机私信发一行，不重复发放，右上角显示剩余数量，发完会私信提醒补货。**不要把爱发电自己的「兑换码」填进自动随机回复**，否则可无限领取。
3. 粉丝在「升级会员 / 续费会员」弹窗粘贴 Key 激活。`POST /api/membership/redeem` 需登录、一次性使用，输入忽略大小写与连字符；时长叠加到当前到期日，并写一条 `membership_grants`（`granted_by = key:XXX`）。
4. 后台「会员激活」的密钥列表为三列紧凑卡片，支持按 Key、激活人 QQ / 昵称、批次检索，并可与「未使用 / 激活记录 / 已作废 / 全部」状态组合筛选。未使用的 Key 可导出或作废；已作废且未激活的 Key 可单条「彻底删除」，或在「已作废」页签「清空已作废」批量彻底删除。已激活的记录不允许删除。

爱发电主页链接存 `site_settings(afdian_url)`，在后台「内容配置 → 赞助会员设置」修改，留空则弹窗只显示 Key 激活与交流群。交流群 917744498 始终保留，作为无法使用爱发电时的备用开通通道。

`membership_keys` 表字段：`key_norm`（规范化主键，大写去连字符）、`code`（明文展示）、`months` / `days` / `batch` / `created_by` / `created_at` / `redeemed_by` / `redeemed_at` / `expires_at` / `revoked_at`。
